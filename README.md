# Screen Ruler

리눅스(X11) 화면 위에 띄우는 반투명 가상 자. A4 같은 실물로 화면 픽셀 크기를 보정한 뒤, 화면에 표시된 물체(예: 체커보드 칸)의 길이를 mm 로 잰다. 실물 자를 화면에 대다가 긁힐 걱정이 없다.

- 테두리 없는 반투명 자 막대, 항상 위에 뜸. 기울이면 창 모양도 자 모양으로 잘려서 바깥은 아래 창이 보이고 클릭도 통과한다
- 임의 각도 회전, 좌우·상하 뒤집기, 길이 조절
- 가로·세로 피치를 따로 보정하고, 모니터별로 저장
- 두 점 사이 길이 측정, 보정 결과 검증

## 요구 사항

- Linux + X11 세션 (Wayland 에서는 창 모양 자르기와 `xrandr` 모니터 정보가 동작하지 않는다)
- Python 3.10+ 와 tkinter
- `xrandr` (모니터 위치·EDID 크기), `libX11` / `libXext` (창 모양 자르기)

외부 Python 패키지는 없다. Ubuntu 기준 시스템 패키지:

```bash
sudo apt install python3-tk x11-xserver-utils libxext6
```

## 실행

```bash
python3 screen_ruler.py                  # 마우스가 있는 모니터에 띄움
python3 screen_ruler.py --monitor DP-4   # 모니터 지정 (xrandr 출력 이름)
python3 screen_ruler.py --length 320 --angle 0
python3 screen_ruler.py --selftest       # 계산 부분 자체 검사
```

끄기: 자 위 `✕` 버튼, 또는 자를 클릭한 뒤 `Esc`. 응답이 없으면 `pkill -f screen_ruler.py`.

## 처음 한 번: 보정

화면 픽셀 1개가 실제로 몇 mm 인지(피치)를 실물로 잰다. `보정하기 (c)` 를 한 번 누르면 **A4 를 가로로 눕힌 채** 두 단계를 차례로 진행하고, 자는 알아서 0° → 90° 로 돈다.

1. **① 가로** (자 0°) — A4 **긴 변(297 mm)** 을 자의 눈금 쪽 가장자리에 붙이고, 파란 선 두 개를 종이 왼쪽·오른쪽 끝에 맞춘 뒤 `Enter`
2. **② 세로** (자 90°) — A4 **짧은 변(210 mm)** 을 자의 눈금 쪽 가장자리에 붙이고, 파란 선 두 개를 종이 위·아래 끝에 맞춘 뒤 `Enter`

끝나면 원래 각도로 돌아오고 `✓ 보정 완료 — 가로 … · 세로 …` 가 표시된다. 한쪽만 다시 할 때는 다른 단계에서 `건너뛰기`, 중간에 그만두려면 `Esc`.

- 선은 드래그하거나, 선을 클릭한 뒤 방향키로 1 px 씩(Shift = 10 px) 옮긴다
- 저장하면 아래 상태줄이 초록 `✓` 로 바뀌고 EDID 대비 차이(%)가 나온다. 보통 1 % 안쪽이고, 5 % 를 넘으면 경고가 뜬다 (대개 종이 변을 잘못 댄 경우)
- 보정 전에는 모니터 EDID 크기로 추정한다
- 보정값은 `~/.config/screen_ruler.json` 에 모니터·축별로 저장된다

> 왜 자를 돌려야 하나: 자를 가로로 둔 채 종이 두 변을 재면 둘 다 "가로 방향 픽셀 수"를 세므로 같은 가로 피치를 두 번 잰 셈이다. 세로 피치는 자를 세워야 잴 수 있다. 요즘 모니터는 픽셀이 사실상 정사각형이라 세로 보정은 그것을 확인하는 용도다.

## 검증

`검증 (t)` 을 누르면 자의 210 mm, 297 mm 위치에 초록 선이 생긴다(점선 = ±1 mm). A4 한쪽 끝을 0 눈금에 맞췄을 때 반대쪽 끝이 초록 선에 오면 보정이 맞다. 가로는 긴 변 297, 세로는 짧은 변 210 으로 확인하고, 다른 변으로 교차 확인해도 된다.

## 길이 재기

1. 자 위를 클릭 → **A 고정**. 이후 `A → 커서` 거리가 계속 표시된다
2. 다시 클릭 → **B**. 클릭할 때마다 B 만 옮겨지고, 방향키로 B 를 1 px 씩 조정할 수 있다
3. `확정 (Enter)` → 결과 고정. 이후 클릭은 무시된다
4. `새 측정 (m)` / 우클릭 / Delete 로 지우고 다시 시작. 확정 전 `Esc` 는 측정 취소

측정은 실물 자처럼 자를 따라가는 방향의 길이다.

## 조작 요약

| 동작 | 버튼 | 키·마우스 |
|---|---|---|
| 자 이동 | 드래그 | 방향키 1 px (Shift 10 px) |
| 90° 회전 | `↺90°` `↻90°` | `r` |
| 임의 각도 | `각도…` → 숫자 입력 → Enter | 휠 1° (Shift+휠 0.1°), `,` `.` 1°, `<` `>` 0.1° |
| 좌우 / 상하 뒤집기 | `⇋좌우` `⇅상하` | `h` / `v` |
| 길이 | `−1cm` `+1cm`, 끝 손잡이 드래그 | `[` `]` |
| 투명도 | | `+` / `-` |
| 보정 / 검증 / 새 측정 | `보정하기` / `검증` / `새 측정` | `c` / `t` / `m` |
| 도움말 / 끄기 | `?` / `✕` | `?` / `Esc` |

자가 모니터보다 길면 화면에 맞게 보이는 길이만 줄이고(원래 길이는 기억), 모니터 밖으로 나가면 안쪽으로 밀어 넣는다.

## 한계

- X11 전용 (Wayland 미지원)
- 모니터는 `xrandr` 출력 이름 + 해상도 + EDID 크기로 구분한다. 같은 모델을 같은 포트에 번갈아 꽂으면 보정값을 공유한다
- 비스듬한 각도에서는 가로·세로 보정값을 합성해 쓴다
